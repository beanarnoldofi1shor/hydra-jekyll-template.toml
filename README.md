# Consideração importante


- Vale conferir a versao instalada antes de seguir os passos abaixo.

Sistemas que automatizam a versão web do WhatsApp com navegador controlado são vistos com desconfiança pela empresa dona do serviço, talvez por questão de monetização da API. Bots assim funcionam, mas é preciso pensar nisso com cuidado. **Não sei exatamente**, mas isso pode levar ao banimento do número que envia as mensagens. Vale ler a documentação da plataforma sobre regras de bots e integrações.
